# 计价口径详解

本文件说明本工具如何把 token 数量换算成金额，以及各口径的取舍依据。

## 一、基本公式

单位统一为 **元 / 百万 token**，价格记作 `[输入价, 输出价, 缓存命中价]`。

```
成本 = 非缓存输入 × 输入价
     + 缓存命中   × 缓存命中价
     + 缓存写入   × 输入价 × 1.25
     + 输出       × 输出价
```

其中 `非缓存输入 = max(0, 输入 token − 缓存命中 − 缓存写入)`。

**为什么必须这样拆**：多数厂商对「缓存命中」的输入单独定价，只有输入价的 1/4 到 1/20。
如果不区分、全部按输入价计，成本会被严重高估（本机实测高估约 70%）。

## 二、三种计价形态

价格表用 `kind` 区分三种形态，**判定粒度都是「每一条请求」**，不是任务或会话。

### 1. `flat` 固定价

单价恒定。混元、MiniMax、商汤、Mistral 属此类。

### 2. `split` 分时价

适用：DeepSeek 系（`deepseek-v4-flash` / `deepseek-v4.1-flash` / `deepseek-v4-pro`）。

| 项 | 规则 |
|---|---|
| 时区 | 北京时间（UTC+8） |
| 高峰窗口 | 工作日 `09:00–12:00`、`14:00–18:00` |
| 空闲窗口 | `00:00–09:00`、`12:00–14:00`、`18:00–24:00` |
| 价格关系 | 高峰价 = 空闲价 × 2 |

**为什么必须逐请求判定**：一个任务可能 11:50 开始、14:30 结束，横跨「高峰 → 空闲 → 高峰」。
用任务开始时刻一刀切会算错该任务内全部请求的时段归属。本机实测常有任务横跨峰谷。

### 3. `tiered` 分段价

适用：智谱 GLM 系列。按**输入 token 长度**分段，部分模型还叠加**输出 token 长度**档。

```json
{
  "kind": "tiered",
  "tiers": [
    {"in_max": 32768, "out_max": 200,  "price": [2, 8, 0.4]},
    {"in_max": 32768, "out_max": null, "price": [3, 14, 0.6]},
    {"in_max": 204800, "out_max": null, "price": [4, 16, 0.8]}
  ]
}
```

判定：取第一个同时满足 `输入 ≤ in_max` 且（`out_max` 为空 或 `输出 ≤ out_max`）的档。
`null` 表示无上限。

> 注意：智谱是**按长度分段**，不是分时。两者容易混淆。

## 三、工作日判定（含节假日与调休）

分时计价依赖「这天是不是工作日」，规则如下（按顺序判定）：

1. 若日期在 **调休上班日** 表中 → 是工作日
2. 若日期在 **法定放假日** 表中 → 不是工作日
3. 否则按周一至周五判断

* 日历按年存放于 `assets/calendar_YYYY.json`，引擎按数据实际涉及的年份自动加载
* 缺某年日历会**显式告警**，该年退化为「仅按周一至周五」判断
* 日历依据：国务院办公厅发布的年度节假日安排通知（通常**前一年 11 月**发布）

**为什么这一条不能省**：某些周日是法定调休上班日（如 2026-09-20），
按普通周日处理会把整天误判为空闲时段。

## 四、价格来源与优先级

**模型原厂价优先**，平台价（腾讯云 TokenHub）作交叉校验。

| 厂商 | 原厂来源 |
|---|---|
| DeepSeek | `api-docs.deepseek.com/quick_start/pricing` |
| 智谱 GLM | `docs.bigmodel.cn/cn/guide/start/pricing` |
| 腾讯混元 | `hy.tencent.com` / 腾讯云计费文档（混元为腾讯自研，原厂即腾讯） |
| MiniMax / 商汤 / Mistral | 各自官网 |

登记表见 `assets/price_sources.json`，含抓取要点与校验锚点。

## 五、更新机制

- **当日第 1 次调用** → 刷新价格表，再统计
- **当日第 2 次及以后** → 跳过刷新，复用当日结果
- **强制** → `--force-refresh`；**离线** → `--no-refresh`

抓取采用**混合模式**：

1. 自动抓取官方页 + 关键词锚点校验（锚点命中率 ≥ 60% 视为通过）
2. 失败或锚点缺失 → 写入 `pending_manual`，输出待人工核实清单

**不静默跳过**：抓取失败的厂商不会被假装更新，会明确列出来。

> 部分官方页面为 JS 动态渲染，纯请求抓不到内容，这类厂商会稳定落入人工清单。
> 此时由使用者（或 AI Agent）用浏览器/WebFetch 核实后写回价格表。

## 六、已知偏差

| 偏差来源 | 说明 |
|---|---|
| 限时促销 | 官网可能打折（如 GLM-5.3-Flash 曾 5 折），本表默认按原价，属**偏高**估计 |
| 限时免费 | 某些模型公测期免费（如商汤 6.8 Flash-Lite 标价全 0），期间成本为 0 |
| 套餐折扣 | 年付/月付折扣不体现在牌价里 |
| 免费额度 | 赠送额度抵扣的消费不会计入账单 |
| 汇率 | Mistral 等 USD 计价模型按固定汇率折算，汇率波动会带来偏差 |
| 官方文档中英文不一致 | 个别厂商中英文页价格或口径不同步，本表取最新且可交叉印证者 |

**结论：本工具给出的是「按官方公开牌价的预估」，不是官方账单。**
绝对金额请以厂商账单为准；本工具的价值在于**相对比较与归因**（哪个任务贵、贵在哪个模型）。
