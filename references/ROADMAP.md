# 路线图与待办

本文件记录已完成项与待办事项，供贡献者参考。

## 已完成

### v1 · 打通数据源
- 确认 WorkBuddy 本机落盘**请求级真实 usage**（`providerData.rawUsage`），非估算
- 打通 `~/.workbuddy/workbuddy.db` 的任务元数据与额度表
- 实现按任务 / 工作空间 / 自动化的三口径聚合

### v2 · 修正计价
- **分时计价**：按每条请求的时间戳判定高峰/空闲（DeepSeek 系）
- **节假日与调休**：显式建模，调休上班日按工作日处理
- **双时长口径**：墙钟跨度 + 活跃时长
- 缓存分档计价（修正「全部按输入价」导致的高估）

### v3 · 可长期维护
- 价格表与日历**外部化**：`price_table.json` / `calendar_YYYY.json`
- **当日首刷**机制：当日首次调用自动刷新，后续复用
- **混合抓取**：自动抓取 + 关键词锚点校验，失败降级为人工清单
- 智谱 GLM 改为**逐请求分段判档**
- 三模式共享同一份价格表

### 开源化
- 去除全部本机硬编码路径，改为脚本相对定位 + `--out` / `--projects` / `--db` 参数
- 新增 MIT LICENSE、README、.gitignore
- 脱敏示例报告生成器（`examples/make_sample.py`）
- 移除代码中硬编码的真实项目名，改为从当前数据动态取例
- 加入安全除法防护，无数据/无额度环境下不再崩溃

### 深整合与工程化（本轮新增）
- **深整合完成**：审计引擎输出 `requests.jsonl`（逐请求明细），`gen_dashboard.py` 改为读统一产出，
  **删除其自带的 JSONL 解析与计价**——同一份日志不再被解析两次
- **计价核心抽取**：新增 `scripts/pricing_core.py`（纯函数、无副作用），引擎、看板、测试共用同一实现
- **独立复算校验器**：`scripts/verify_cost.py` 用**独立实现**重算全部成本并与引擎对比
  （实测 4 万条请求：时段判定 0 处不一致、计价 0 处不一致）
- **单元测试**：`tests/` 46 个用例，覆盖价格匹配优先级、峰谷判定（含调休日/法定假日）、
  分段判档、缓存分档公式、安全除法、价格表与日历的数据契约
- **敏感扫描**：`scripts/check_privacy.py`，检出本机绝对路径、产出数据误入库、大文件等
- **脱敏开关**：报告生成器支持 `--anonymize`（任务名/工作空间名哈希化）
- **CI**：`.github/workflows/ci.yml`，三平台 × 三 Python 版本跑语法检查、单测、敏感扫描、示例冒烟
- 旧 `token-dashboard` / `token-consumption-tracker` 已归档，全部引用改为指向本 skill

| 限制 | 原因 |
|---|---|
| 依赖未公开的日志格式 | 客户端私有格式，官方调整即可能失效；已在 README 声明非官方 |

| 成本为牌价预估 | 套餐折扣、限时促销、免费额度均会造成偏差 |
